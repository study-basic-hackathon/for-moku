# 表示すべき項目の整理
- 共通
- イベント
  - イベント新規作成
  - イベント一覧
- ユーザ
  - マイプロフィール
- ユーザグループ
  - グループ管理画面（1ユーザは0..Nのグループに紐づくので必要）
    - 自分が管理するグループの一覧がわかる
    - 自分が属しているグループの一覧がわかる
    - 自分が管理するグループへの詳細画面に遷移できる
    - 自分が属しているグループへの詳細画面に遷移できる
    - グループの新規作成画面に遷移する

# 結局サイドメニュー必要な項目
- ダッシュボード
- マイプロフィール
- グループ管理画面
- イベント一覧
- イベント新規作成
