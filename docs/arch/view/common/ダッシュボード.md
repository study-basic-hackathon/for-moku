  - ユーザ
  - ユーザグループ管理
  - 当日ページ
- ことあるごとにリダイレクトされる

# ダッシュボードに載せておきたいもの
- イベント関連の画面へのリンク
  - イベント詳細への遷移
- ユーザ関連画面
  - 自分のプロフィール確認
- 当日ページへのリンク
  - イベントへのリンク
- 情報が一目でわかるもの
  - このアプリケーションはイベントを管理する
  - したがって、イベントの状況を楽に確認できるのが望ましい。
    - いつイベントがあるのか
    - なんのイベントがあるのか
    - どこで開かれるのか（これはいらない）
  - カレンダーでいいのでは？と思います

# ダッシュボードの構成
- カレンダー(自分が属するユーザグループに紐づくイベントを表示できたら最高)
- プラスアルファ（正直特にないのでは）
  - 直近のイベント(→カレンダーでいいような気がする)
  - 自分のプロフィール確認（→カレンダーでいいような気がする）
  - サイドメニューに乗せてくれるとありがたい
