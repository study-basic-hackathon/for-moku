## 3.2 自分の座席アイコンを置く機能

画像の上に自分のアイコンを置けるようにする

- 参加者が間取り上の座席をクリックすると確認プロンプトが現れ、自分の席として登録できる
- そうするとその席のところにユーザの名前が他のユーザにも表示され、プロフィール編集が可能が画面が現れる（3.3）
- ログインしたユーザであればデフォルトで事前登録したプロフィール情報が記入される
- できればWebSocketを利用してリアルタイムにしたいのですが、優先度低め？(Brian)

## 3.3 自分の座席アイコンにプロフィールを書き込み

自分のアイコンの上に、プロフィールを書き込む

- connpass ID

## 3.4 他の参加者の状況を確認

優先度：高、難易度：高（山下）

リアルタイムで更新できる。

実装をどうするかは別として、あるとサービスの価値はかなり上がる

他のユーザの座席をクリックするとそのユーザの自己紹介などが閲覧できる

WebSocketで完全同期 → 一定時間でリフレッシュ → 更新前に最新情報をfetch → リフレッシュボタン
